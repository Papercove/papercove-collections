# Web development

Curated by: Papercove  
Language: English  
Description: The web platform, CSS, JavaScript and accessibility, explained by the people pushing it forward.

- [Josh W. Comeau](https://www.joshwcomeau.com/rss.xml): Beautifully interactive deep dives into CSS, React and animation that make hard concepts click, every month or so.
- [WebKit Blog](https://webkit.org/feed/): New web platform features, standards work and Safari release notes, straight from the WebKit team. A few posts a month.
- [Jeremy Keith](https://adactio.com/journal/rss): Thoughtful journal entries on the web, progressive enhancement and the craft of building for everyone, a couple a week.
- [web.dev](https://web.dev/static/blog/feed.xml): Google's guidance on modern web capabilities, performance and Baseline browser support, a few posts a month.
- [Rachel Andrew](https://rachelandrew.co.uk/feed/): A CSS layout expert and spec contributor on web platform features and documentation, about twice a month.
- [Chrome for Developers](https://developer.chrome.com/static/blog/feed.xml): What's new in Chrome, DevTools and upcoming web APIs, several posts a month.
- [Chris Coyier](https://chriscoyier.net/feed/): The CodePen co-founder's short, curious notes on front-end development and the web, several posts a week.
- [Piccalilli](https://piccalil.li/feed.xml): Andy Bell and guests on CSS, accessibility and resilient front-end practices, a couple of posts a week.
- [Eric Meyer](https://meyerweb.com/eric/thoughts/feed/): A CSS pioneer on CSS, web standards and the history of the web, several posts a year.
- [OddBird](https://www.oddbird.net/feed.atom): The team behind several CSS specs on new CSS features, Sass and web standards, a couple of posts a month.
- [Zach Leatherman](https://www.zachleat.com/web/feed/): The creator of Eleventy on web performance, fonts and static sites, about once a month.
- [Frontend Masters Blog](https://blog.master.dev/feed/): Practical articles on modern CSS, JavaScript and front-end tooling from expert authors, a few posts a week.
- [Manuel Matuzović](https://www.matuzo.at/feed.xml): Accessibility and HTML done right, explained with concrete examples, a couple of posts a month.
- [Smashing Magazine](https://www.smashingmagazine.com/feed/): Long-form articles on front-end development, accessibility and UX, a couple of posts a week.
- [Lea Verou](https://lea.verou.me/feed.xml): CSS, web standards and API design from a CSS Working Group member and MIT researcher, every month or two.
- [Frontend Focus](https://frontendfoc.us/rss/): A weekly newsletter rounding up the best HTML, CSS, accessibility and browser news.
- [Bramus Van Damme](https://www.bram.us/feed/): A Chrome DevRel engineer on new CSS features like view transitions and scroll-driven animations, a couple of posts a week.
- [Hidde de Vries](https://hidde.blog/feed): Accessibility, web standards and the open web from a W3C contributor, about once a month.
- [JavaScript Weekly](https://javascriptweekly.com/rss/): The essential weekly roundup of JavaScript news, articles, releases and tools.
- [Mozilla Hacks](https://hacks.mozilla.org/feed/): Mozilla engineers on Firefox, web platform features and developer tools, several posts a year.
